## Quest briefing

Nightwatch answers a simple question: what's the *safest* way to walk home
at night, not just the shortest? Built at CUMSA Hacks, where it placed
**Top 5**.

![Nightwatch demo](/images/projects/nightwatch/newdemo.gif)

- Built a FastAPI backend that computes safest-vs-shortest routes by
  scoring paths with streetlight density from Ottawa Open Data.
- Designed Pydantic schemas with nested models and validation to enforce
  strict API contracts and reject malformed requests at the boundary.
- Implemented pytest integration tests with FastAPI's TestClient to
  validate routing endpoints and schema correctness.

![Nightwatch app screenshot](/images/projects/nightwatch/IMG_7052.jpg)

## Loot (what was learned)

- Open municipal data is a goldmine — the hard part is normalizing it
  into something routable.
- Schema-first API design catches whole classes of bugs before any route
  logic runs.
- Hackathon scope control: one sharp feature beats five half-built ones.
