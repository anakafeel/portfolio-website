## Commands

This project uses **pnpm** (see `packageManager` in package.json).

- `pnpm dev` — start the Next.js dev server at http://localhost:3000
- `pnpm build` — production build (also the main type/correctness check; there are no tests)
- `pnpm lint` — run ESLint via `next lint`
- `pnpm slicemachine` — start the Slice Machine UI for editing Prismic slices and custom types (pairs with the dev server; the slice simulator lives at `/slice-simulator`)

## Architecture

Next.js 15 App Router portfolio site with **Prismic as the headless CMS**. All page content is modeled in Prismic and rendered through slices; most work involves either a slice component or a route that fetches a Prismic document.

### Content flow

1. `src/prismicio.ts` creates the Prismic client. It defines the route resolver (`homepage` → `/`, `page` → `/:uid`) and the caching strategy: in production, requests use `force-cache` tagged `"prismic"`; in dev they revalidate every 5 seconds.
2. `POST /api/revalidate` calls `revalidateTag("prismic")` — this is the Prismic webhook target that busts the production cache on publish. `/api/preview` and `/api/exit-preview` handle Prismic draft previews.
3. Routes (`src/app/page.tsx`, `src/app/[uid]`, `src/app/blog/[uid]`, `src/app/project/[uid]`) fetch a document by type/UID and render its slices via `<SliceZone components={components}>`. Dynamic routes use `generateStaticParams` from `getAllByType`.

### Slices and generated code

- `src/slices/*` — one directory per slice (Biography, ContentIndex, Experience, Homepage, TechList, etc.). This is where most UI lives.
- `src/slices/index.ts` — the slice registry, **generated by Slice Machine, do not edit by hand**.
- `prismicio-types.d.ts` — generated Prismic document/slice types; regenerate through Slice Machine rather than editing.
- `customtypes/` — Prismic custom type definitions (blog_post, homepage, page, project, settings) managed by Slice Machine.
- `slicemachine.config.json` — Prismic repository name (`new-portfolio-website`); can be overridden with `NEXT_PUBLIC_PRISMIC_ENVIRONMENT`.

### Layout and styling

- `src/app/layout.tsx` renders `Header`/`Footer` around every page plus the site-wide background gradient and noise texture overlays.
- Shared presentational components in `src/components/` (`Bounded` for section padding/width, `Heading`, `Button`).
- Tailwind CSS with `prettier-plugin-tailwindcss` for class sorting.
- Animation stack: GSAP for scroll/entrance animations, react-three-fiber + drei for 3D (e.g. the Homepage slice's `Computers.jsx` model), react-spring. Respect `prefers-reduced-motion` (the `@magica11y/prefers-reduced-motion` helper is used for this).

### Path alias

`@/*` maps to `src/*` (see tsconfig.json).
